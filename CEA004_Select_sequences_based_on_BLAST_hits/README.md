# CEA004_Selected_sequences_based_on_BLAST_hits

## 1. Description
   The Selected_sequences_based_on_BLAST_hits algorithm is developed to select nucleotide sequences that either have or do not have a hit after a CEA001_Blastn or CEA002_DIAMOND analysis. These sequences are then written to a fasta file for further analysis.

## 2. Version
   CEA004_Selected_sequences_based_on_BLAST_hits_v3.0

## 3. Front-end
### 3.1 Input
CEA004 expects a blast table file from CEA001 or CEA002. Additionally, CEA004 
requires a file with nucleotide sequences in fasta format (*.fa, *.fas, 
*.fasta, etc.), as obtained after generating an assembly, consensus sequence, 
or as generated by CEA003_Chunk_file.

### 3.2 Output
CEA004_Select_chunks_without_hits produces a file with nucleotide sequences 
in fasta format (*.fasta).

### 3.3 Configurable Parameters
The parameters used for CEA004 are described in Table 1. 

_Table 1: Configurable parameters for CEA004, as entered in the command_ 
_(script), and how it appears in CLC for the user (CLC). The CLC input/output_ 
_settings represent what CLC fills in the command for the parameters in the_ 
_background._

  
| CLC          | description                                                                                                                             | CLC Input/output settings                                      |
|--------------|-----------------------------------------------------------------------------------------------------------------------------------------|----------------------------------------------------------------|
| blast_table  | File generated by CEA001_BLASTn or CEA002_DIAMOND                                                                                       | User-selected input data(CLC data location) – text(.txt/.text) |
| fasta_input  | File with nucleotide sequences (used in the BLAST/DIAMOND analysis) User-selected input data(CLC data location) – FASTA(.fa/.fsa/.fasa) |                                                                |
| blast_switch | Choice between BLASTn or BLASTx hit table                                                                                               | Csv enumerator: BLASTn, BLASTx                                 |
| hits_switch  | Choice between "hits" or "no hits"                                                                                                      | Csv enumerator: hits, nohits                                   |
 


## 4. Back-end
### 4.1 Terminal Execution
   `/path/to/CEA004_Select_sequences_based_on_BLAST_hits_V3.py {blast_table} {fasta_input} {fasta_output} {blast_switch} {hits_switch}`

### 4.2 Requirements
The script uses Python 3 and BioPython v1.74. Could work with newer versions, but is not tested.
