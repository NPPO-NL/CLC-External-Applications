# CEA005_Krona

## 1. Description
   The Krona program creates an interactive circular diagram from a blast output. This circular diagram contains taxonomic information about found hits and can display the found hits at each taxonomic level. It is then possible to determine which "blasted" sequence corresponds to each wedge in the diagram. The circular diagram can be colored according to various statistics (Ondov et al. 2011).

## 2. Version
   CEA005_Krona_V1.1
   Contains: KronaTools-2.8.1

## 3. Front-end
### 3.1 Input
        CEA005_Krona expects at least one hit table from BLASTn or BLASTx as generated by CEA001_Blastn and CEA002_DIAMOND.

### 3.2 Output
        CEA005_Krona produces a circular diagram in .html that visualizes all BLAST results.

## 4. Back-end
### 4.1 Terminal Execution
   
`/path/KronaTools/KronaTools-2.7.1/scripts/ImportBLAST.pl -o {out} {Include a wedge for queries with no hits} {Statistic to use for scores} -t {Threshold for bit score differences when determining "best" hits.} {BLAST1 result} {BLAST2 result} {BLAST3 result} {BLAST4 result} {BLAST5 result}`

### 4.2 Requirements
Krona, taxonomy, and accession tables are required. Further installation 
requirements can be found in the installation instructions, available at 
[https://github.com/marbl/Krona/wiki/Installing](https://github.com/marbl/Krona/wiki/Installing).
